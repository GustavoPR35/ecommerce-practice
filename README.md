# E-commerce

Este repositório contém o frontend de um projeto de e‑commerce construído com React e Vite.

**Status:** Frontend funcional. O backend será implementado futuramente.

**Tecnologias:** React, Vite, Tailwind CSS, ESLint.

### Pré-requisitos

- Node.js 18+ e npm (ou pnpm / yarn).

### Instalação

Instale dependências:
```
npm install
```

Iniciar em modo de desenvolvimento:
```
npm run dev
```
Estrutura principal do frontend

- `src/`: código fonte React
   - `components/`: componentes reutilizáveis (Navbar, ProductCard, etc.)
   - `contexts/`: Context APIs (carrinho, filtros)
   - `pages/`: páginas (StorePage)
   - `assets/`: imagens e outros recursos

### Backend (futuro)

O backend ainda não foi implementado, será adicionado futuramente para fornecer APIs de produtos, autenticação e persistência de carrinho.
